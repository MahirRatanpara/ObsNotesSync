## 📝 Execution Guidelines

### Time Management (Per Problem)

1. **0-10 min:** Understand problem, think of approach
2. **10-15 min:** If stuck, look at hints/pattern
3. **15-30 min:** Code the solution
4. **30-35 min:** Test with edge cases and optimize

**⚠️ Hard Rule:** If you can't solve in 35 minutes, MOVE ON. Mark it for evening review.

---

## 🎯 Key Focus Areas (Based on Recent Amazon Interviews)

### High Priority Topics:

- **Trees & Graphs:** DFS, BFS, Topological Sort, Union Find
- **Dynamic Programming:** 1D, 2D, String DP, Interval DP
- **Sliding Window:** Fixed & Variable size windows
- **Heaps:** Min/Max heap, K-way merge
- **Design:** LRU Cache, Data structure design
- **Advanced Data Structures:** Trie, Segment Tree, Monotonic Stack/Queue

### Problem-Solving Strategies:

1. **Always ask clarifying questions**
2. **Start with brute force, then optimize**
3. **Think out loud during interviews**
4. **Test with edge cases**
5. **Analyze time & space complexity**
