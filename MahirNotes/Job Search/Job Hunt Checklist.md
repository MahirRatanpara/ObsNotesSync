# 🧠 SDE-2 Job Hunt System – Full Execution Plan 

This note is a comprehensive job search strategy for Software Development Engineer 2 (SDE-2) roles, especially in India with Java, Scala, and GCP backend experience.

It is organised into **two main phases**, each with detailed checklists, explanations, and free tools to help you succeed.

---

## ✅ PHASE I – Passive Inbound Strategy: Make Recruiters Find You

### 🎯 Goal:
Increase your **visibility in recruiter searches** so that inbound calls and messages happen automatically.

---
### 🔹 STEP 1: Resume Optimization (ATS + Human-Readable)

Most resumes are rejected by software (Applicant Tracking Systems - ATS) **before** a human sees them.

#### What to do:
- [x] Keep it to **1 page only**.
- [x] Focus on **impact + scale + ownership**.
- [x] Each bullet must follow: **Action + System + Scale + Result**
  - ✅ Good: `Designed Kafka pipeline handling 5M+ events/day, reducing processing latency by 38%`
  - ❌ Bad: `Worked on Kafka pipelines`

#### Free Tools to Help:
- [Jobscan Resume Optimizer](https://www.jobscan.co/)
- [Resume Worded](https://resumeworded.com/)
- [Teal Resume Builder](https://www.tealhq.com/)

---

### 🔹 STEP 2: LinkedIn Optimization for Recruiter Search

Recruiters use LinkedIn Recruiter Lite with keyword filters. You want to **appear in their search results**.

#### What to do:
- [x] Update **Headline** with keywords:
  `SDE-2 | Backend / Distributed Systems | Java, Scala, GCP`
- [x] Rewrite **About** section with dense keyword bullets:
  ```
  SDE-2 backend engineer with 5+ years experience.
  Tech:
  - Java, Scala
  - Kafka, GCP, Microservices
  - Distributed Systems, REST APIs
  - System Design
  Open to SDE-2 backend roles in India or remote.
  ```
- [x] Update **Skills section** (top 8 keywords):
  - [ ] Java
  - [ ] Scala
  - [ ] GCP
  - [ ] Kafka
  - [ ] Distributed Systems
  - [ ] Microservices
  - [ ] REST APIs
  - [ ] System Design

#### LinkedIn Settings:
- [x] Set “Open to Work” → **Recruiters only**
- [ ] Preferred Roles: Software Engineer, Backend Engineer
- [ ] Add locations: Bangalore, Pune, Hyderabad, Remote

---

### 🔹 STEP 3: Build Passive Inbound Presence

Recruiters often scan GitHub, blogs, and public content to verify backend depth.

#### What to do:
- [ ] Pin 1–2 backend projects on GitHub with READMEs that include:
  - Architecture diagram / explanation
  - Design tradeoffs made
  - Tech stack used
  - Sample queries, latency benchmarks, etc.
- [ ] Make 1 LinkedIn post/week sharing:
  - A system design insight
  - Kafka optimization you worked on
  - GCP scalability decision

This builds **personal brand signals**.

---

### 🔹 STEP 4: Apply to Recruiter-Pull Platforms

Create and upload resume to platforms where recruiters come to **you**.

#### What to do:
- [ ] Sign up and apply on:
  - [ ] [Instahyre](https://www.instahyre.com)
  - [ ] [CutShort](https://cutshort.io)
  - [ ] [Hirist](https://hirist.com)
  - [ ] [Indeed India](https://in.indeed.com)
- [ ] Upload keyword-rich resume

#### Tools:
- [Teal Extension](https://www.tealhq.com): Save jobs + auto-optimize resume
- [Huntr](https://huntr.co): Tracker + resume builder

---

## 🟧 PHASE II – Active Outreach + Recruiter CRM Tracking

### 🎯 Goal:
Proactively identify, contact, and **maintain relationships** with recruiters at your target companies.

---

### 🔹 STEP 1: Find Recruiters (Per Company)

Use LinkedIn advanced search to find recruiter contacts.

#### What to do:
- [ ] Search: `"recruiter OR talent acquisition AND <Company>"`
- [ ] Filter by India
- [ ] Visit their profiles
- [ ] Copy profile link + name

---

### 🔹 STEP 2: Get Recruiter Emails (Free Tools)

Most recruiter emails follow patterns. Use free tools to extract them.

#### Tools (Free Tiers):
- [ ] [Hunter.io](https://hunter.io) – 25/month
- [ ] [Apollo.io](https://apollo.io) – 50/year
- [ ] [Mailmeteor LinkedIn Email Finder](https://mailmeteor.com/tools/linkedin-email-finder)
- [ ] [LeadLeaper](https://leadleaper.com) – 200/month
- [ ] [Skrapp.io](https://skrapp.io) – 100/month
- [ ] [Kaspr.io](https://kaspr.io) – 15/month

---

### 🔹 STEP 3: Message Templates (LinkedIn + Email)

Use professional, short, and polite messages.

#### LinkedIn Message
```
Hi <Name>,

I’m an SDE-2 backend engineer with Java, Scala, and GCP experience.
I recently applied for <Role> at <Company> and would love to connect.

Thanks!
```

#### Email Template (Attach Resume)
```
Subject: SDE-2 Backend Engineer – <Company>

Hi <Name>,

I’m a backend SDE-2 working on distributed systems (Java, Kafka, GCP).
I applied to <Role> and wanted to reach out directly.

Would love to explore if my background fits your team.
Resume attached.

Best,
<Your Name>
```

---

### 🔹 STEP 4: Create Your Recruiter CRM (Tracker)

Choose any of these to track recruiter outreach:

#### Tools:
- [ ] [Google Sheets](https://docs.google.com) – manual but free
- [ ] [Notion](https://www.notion.so) – create databases for companies + recruiters
- [ ] [Huntr](https://huntr.co) – full tracking + follow-up board
- [ ] [Teal](https://www.tealhq.com) – CRM + reminders + custom fields
- [ ] [HubSpot CRM](https://www.hubspot.com/products/crm) – most powerful (free)

#### Suggested Columns:
- Company
- Role
- Recruiter Name
- LinkedIn URL
- Email
- Contact Date
- Status (Contacted / Replied / Interview / Rejected)
- Next Follow-up
- Notes

---

### 🔹 STEP 5: Follow-Up Cadence

Use a structured follow-up pattern to improve responses.

| Time       | Action                  |
|------------|--------------------------|
| Day 0      | Initial message sent     |
| Day 7      | Polite follow-up         |
| Day 30     | Status check             |
| Every 3 mo | Keep-warm ping           |

#### Keep-warm ping example:
```
Hi <Name>,
Just a quick note – I recently worked on optimizing GCP microservices for latency. Still open to backend SDE-2 roles. Would love to stay in touch!
```

---

## 📅 Weekly Execution Plan

### 🗓 Daily (30–45 min)
- [ ] Apply to 5 roles
- [ ] Reach out to 5 recruiters (LinkedIn or email)
- [ ] Update tracker

### 🗓 Weekly (1–2 hrs)
- [ ] Resume refresh
- [ ] Post on LinkedIn or update GitHub project
- [ ] Reconnect with cold recruiters

---

## 🔚 Closing Note

Phase I gives you **passive visibility**.  
Phase II gives you **active control**.

If you run both consistently, you will absolutely increase recruiter calls, interviews, and offers.
