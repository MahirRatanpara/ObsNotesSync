## ⏱️ Complexity Analysis

### **Time Complexity Quick Reference**

| **Operation** | **Best Case** | **Average** | **Worst Case** |
|---------------|---------------|-------------|----------------|
| Array Access | O(1) | O(1) | O(1) |
| Array Search | O(1) | O(n) | O(n) |
| Array Insertion | O(1) | O(n) | O(n) |
| Binary Search | O(1) | O(log n) | O(log n) |
| Merge Sort | O(n log n) | O(n log n) | O(n log n) |
| Quick Sort | O(n log n) | O(n log n) | O(n²) |
| DFS/BFS | O(V + E) | O(V + E) | O(V + E) |
| Dijkstra | O((V + E) log V) | O((V + E) log V) | O((V + E) log V) |

### **Space Complexity Guidelines**

- **O(1):** Iterative solutions with few variables
- **O(log n):** Recursive solutions on balanced trees
- **O(n):** Hash tables, additional arrays
- **O(n²):** 2D DP tables, adjacency matrices

## 🧪 Interview Simulation

### **📋 Mock Interview Checklist**

**Before Coding:**
- [ ] Ask clarifying questions about inputs/outputs
- [ ] Discuss edge cases and constraints
- [ ] Explain your approach in plain English
- [ ] Analyze time/space complexity

**While Coding:**
- [ ] Write clean, readable code
- [ ] Use meaningful variable names
- [ ] Handle edge cases explicitly
- [ ] Test with provided examples

**After Coding:**
- [ ] Trace through your solution step-by-step
- [ ] Discuss potential optimizations
- [ ] Mention alternative approaches
- [ ] Be ready to debug if needed

### **⚡ Common Mistakes to Avoid** #pitfalls

1. **Off-by-one errors** in loops and array indexing
2. **Null pointer exceptions** without proper checks
3. **Integer overflow** in sum/multiplication problems  
4. **Infinite loops** in graph traversal without visited sets
5. **Incorrect base cases** in recursive solutions
6. **Memory leaks** in languages requiring manual memory management
