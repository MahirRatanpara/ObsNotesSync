# 1 — Time Allocation Strategy (per day & per week — flexible patterns)

You will work **8 hours/day**. Use two alternating day _patterns_ so you rotate between heavy DSA practice and design/depth days.

- **4 × DSA-Focus Days** (deep coding & mocks)

# 2 — Master Plan Overview (phases & goals)

Phases are **pattern-based**, not locked to calendar dates. You can compress to 4 weeks or stretch to 8 weeks.

## Phase 0 — Quick Restart (3–7 days)

**Goal:** measure current level, build momentum, baseline tests.

- Do a diagnostic: 6 problems (2 easy, 3 medium, 1 hard) timed; 1 LLD design sketch; 1 HLD question.

- Create a heatmap of weaknesses (algorithms, data structures, system topics).

- Set baseline metrics (solve time, success rate, mock score).


## Phase 1 — Deep Revision (3–4 weeks)

**Goal:** re-learn and solidify fundamentals across DSA, LLD, HLD; build a “core” you can apply under pressure.

- DSA: finish NeetCode150 + AlgoMaster patterns + 60% of your custom hard list (mixed).

- LLD: rework design patterns + implement 8–10 canonical designs.

- HLD: study Alex Xu Vol 1 + Vol 2 high-impact designs; practice verbal frameworks.

- Java/Spring: core topics solid, 1 small Spring Boot microservice example.


## Phase 2 — Practice + Mock Interviews (2–3 weeks)

**Goal:** convert knowledge to interview performance.

- Increase mocks: 2 → 3/week (pair / platforms / peer).

- Company-wise problem practice and timed problem sets.

- End each mock with concrete corrective action & 3-item learning list.


## Phase 3 — Resume + Job Strategy (1 week, overlapping)

**Goal:** polish resume + LinkedIn, target applications, build referral pipeline.

- Finalize resume + 2-page project sheet for interviews.

- 100 targeted applications + outreach messages drafts; start referrals.


## Phase 4 — AI/LLM Skill Build (rolling, low priority but practical)

**Goal:** finish 1–2 small agent projects for resume differentiator.

- RAG assistant for a document set OR a simple agent that automates a developer task.

- Keep it light: 6–12 hours/week initially, intensify after interview readiness.

## DSA — **Top priority (highly detailed)**

### Resources to use (as requested)

- **LeetCode** (primary practice + company lists)

- **NeetCode 150** (core set)

- **AlgoMaster DSA Patterns** (patterns practice). — follow their pattern drill layout.

- **Your custom 200 hard problems** (prioritize high-value ones)

- **Company-wise list extraction** (strip company tags & practice)


### Overall revision strategy

1. **Assess & categorize**: Tag each problem in your personal list with: _pattern_, _difficulty_, _company relevance_, _solved?_.

2. **Pattern-first approach**: Learn pattern → 3 guided problems → 3 timed repeats (spaced).

3. **Interleaving**: Mix patterns daily (don’t do 5 graph problems in a row).

4. **Active recall**: After solving, write a 2-sentence summary: pattern + trick.

5. **Refactor & optimize**: Re-implement each solved problem using improved approach or faster complexity.

6. **Journal**: Keep a short log: time taken, mistakes, hint used, final complexity.


### Must-solve patterns / list (minimum)

- **Array & Two-Pointers**: sliding window, partitioning.

- **Hashing**: frequency maps, two-sum variants.

- **Sorting & Binary Search**: binary search on answer, lower/upper bound.

- **Heap / Priority Queue**: k-largest, merge k lists.

- **Stacks & Queues**: monotonic stack, sliding min/max.

- **Linked List**: fast/slow pointers, cycle detection, reverse.

- **Trees & BST**: recursion, iterative traversal, tree DP, BST properties.

- **Graphs**: BFS/DFS, topological sort, SCC, Dijkstra, Bellman-Ford when needed.

- **Union-Find**: connectivity, dynamic connectivity.

- **Dynamic Programming**: 1D/2D DP, knapsack, LIS, DP on trees, DP with bitmask (if applied).

- **Backtracking**: permutations, combinations, pruning.

- **Greedy**: interval scheduling, greedy with proof sketch.

- **Bitwise**: XOR tricks, bit masks.

- **Advanced**: segment tree / fenwick (BIT), suffix arrays/trie-level familiarity, rolling hash.


### Milestones & measurable targets (suggested for intense 1–2 month plan)

- **Week 1 (Restart week)**: Diagnostic + finish NeetCode 150 _first pass_ — (mark problems you solved vs need rework).

- **By end of Deep Revision (wk 3–4)**:

- Complete **AlgoMaster patterns** (all pattern categories).

- Solve **NeetCode150 fully with review**.

- Solve **~60 company-tagged problems** (mix).

- Solve **~40 problems from your custom 200 hard** (prioritize highest impact).

- **During Practice Phase**:

- Continue custom hard list to **100+**, but focus on mixed mocks.

- Achieve average **solve time**: easy 12–15m, medium 25–35m, hard 45–80m (under interview pressure).

- **Final Polishing (last 7–10 days)**:

- Blitz: 2× daily timed sets: (3 medium in 60m) + (1 hard in 60–90m).

- 10 problem re-reads of previously failed problems (fix mental leaks).


### Mixed practice strategy

- **Technique**: 50% new problems, 30% revision of solved problems (spaced), 20% timed mixed sets + interview simulations.

- **Daily micro cadence** (on a DSA day):

- 90–120m deep problem (hard or medium) — full writeup + optimize

- 60m pattern practice: 2–3 mid problems timed

- 60m review & write summaries + code refactor

- 60m timed set (mock interview problem or company set)

- Remaining time: editorial reading, flashcards, and short warm-ups


### Weekly mocks & interview practice

- **Minimum**: 2 mock interviews/week (peer/platform), ramp to 3 in practice phase.

- **Mock format**: 1.5–2 hr session (problem + follow-up + feedback).

- **Post-mock**: 30–60m note/action list and schedule repair tasks.


### Final polishing plan (last week before active application)

- Focus on failures: list top 15 recurring failure patterns and practice 3 problems each.

- Do speed drills: 15× 30-minute mixed sets over the week.

- Oral explanation: for 30 key problems, practice explaining solution out loud in ≤5 minutes.

# 8 — Study hygiene, momentum tricks & discipline tips

- **Start with the hardest brain task** (DSA deep) when fresh.

- Use **Pomodoro** blocks inside the 8h day (90/30 works well for deep work).

- Keep a _mistake log_ — each problem you fail, add 1 line: cause + fix.

- **Spaced repetition**: revisit each solved problem at 3 days → 7 days → 21 days.

- **Accountability**: 1 weekly debrief with a peer or coach; audio-record one explanation per week.

- **Energy management**: sleep, diet, 30m walk midday.

- **Avoid overfitting** to one company — diversify practice.
